# React 19 + Vite Smart Room Lighting Dashboard

## 1. Overview
A modern IoT dashboard for monitoring and controlling the FPGA-based smart lighting system. Built with React 19, Vite, Tailwind CSS, Lucide React, and Recharts.

## 2. Installation and Execution

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Step 3: Production Build
```bash
npm run build
```
The compiled assets will be located in `dist/`.
